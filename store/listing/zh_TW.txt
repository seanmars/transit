Transit 讓你在原文的位置直接閱讀譯文。網頁、影片字幕與文件都能使用，原本的字型、排版與連結會保留下來。可以選擇 8 種目標語言。

■ 主要功能

・網頁：把頁面上的外文換成譯文，排版不變。連結仍可點擊，粗體與斜體也會保留。
・單語與雙語模式：在工具列圖示的選單一鍵切換。雙語模式會在每段原文下方顯示對應的譯文。
・YouTube 字幕：播放時即時轉換字幕，也可以上下兩行同時顯示原文與譯文。
・文件：上傳電子書、文書檔或影片字幕檔，完成後下載整份譯文。PDF 會保留原版面，字幕會保留原本的時間軸。
・懸停與選取：只處理游標所在的段落，或是你選取的文字。
・繁簡中文互轉（免費）：在你的裝置上用內建字典轉換，不需要網路。
・自動備援：主要引擎失敗時，自動改用備用的服務。沒有 API Key 也可以使用。
・統一譯名：自訂人名與專有名詞的譯法，也可以排除不想出現的用詞，讓整頁的譯名前後一致。
・指定網站自動執行：開啟你指定的網站時自動開始。也可以用頁面上的懸浮按鈕或快速鍵 (Alt+S) 啟動。

■ 引擎

・免費引擎：Google Translate，不需要 API Key。
・Google Gemini：品質較好，需要你自己的 API Key。
・自訂模型：任何 OpenAI 相容的端點，包含在你電腦上執行的本機模型。

■ 隱私

・設定與 API Key 只儲存在你的瀏覽器中。
・Transit 沒有自己的伺服器，不會把任何資料傳給開發者。
・要處理的文字會直接送到你選擇的服務。
・使用本機模型時，資料不會離開你的電腦。
・完整的對外連線清單請見隱私權政策：https://seanmars.github.io/transit/privacy-policy.html
