Transit shows the translation right where the original text was. It works on web pages, video subtitles and documents, and keeps the original fonts, layout and links. You can choose from 8 target languages.

■ Features

• Web pages: replaces foreign text in place and keeps the layout. Links still work. Bold and italic text stay the same.
• Replace or Bilingual: switch with one click in the toolbar menu. Bilingual mode shows the result below each source paragraph.
• YouTube subtitles: converts subtitles in real time while the video plays. It can also show both languages as two lines.
• Documents: upload an e-book, a document or a video subtitle file, and download the full result. PDF output keeps the original page layout. Subtitles keep their original timing.
• Hover and selection: process only the paragraph under the cursor, or only the text you select.
• Chinese script conversion (free): converts between Traditional and Simplified Chinese on your device with a built-in dictionary. Works offline.
• Failback: if the primary service fails, Transit switches to a backup automatically. It works without an API key.
• Consistent names: set your own wording for names and terms, and block words you do not want, so names stay the same across the page.
• Per-site automation: Transit starts automatically on sites you choose. You can also start it with the floating button or the keyboard shortcut (Alt+S).

■ Engines

• Free option: Google Translate, no API key needed.
• Google Gemini: better quality, needs your own API key.
• Custom model: any OpenAI-compatible endpoint, including a model that runs on your own computer.

■ Privacy

• Your settings and API keys are stored only in your browser.
• Transit has no server of its own and sends no data to the developer.
• Text goes directly to the service you choose.
• With a local model, your data does not leave your computer.
• For the full list of network connections, see the privacy policy: https://seanmars.github.io/transit/privacy-policy.html
